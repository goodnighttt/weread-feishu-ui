# WeRead Feishu UI

一个用于 **微信读书网页版** 的 Tampermonkey 用户脚本，把微信读书重新呈现为更接近 **飞书云文档** 的界面。

项目不会替代微信读书本身：登录、书籍数据、章节内容和阅读能力仍然由微信读书提供，本项目主要负责界面的重新设计与交互整合。

## 0.5.9 正文加载提示

阅读页标题下说明正文会按阅读进度逐步加载；滚动接近当前正文末尾时提示「继续滚动以加载后续内容」，采集到新增文字后短暂提示「已补充正文，请继续阅读」。提示不代表整章已加载，不会自动遍历章节。

## 0.5.8 目录点击修复

目录文字仍使用飞书外观，点击区域使用微信读书原有的目录节点。修正了原生目录 `display: none` 导致透明行无尺寸的问题，点击区域随目录滚动和窗口尺寸更新，且在收起目录、关闭主题或离开阅读页时撤销。折叠按钮和其他工具栏不被透明区域覆盖。

优先读取原生目录；如果目录节点提供 UID 则按 UID 匹配，否则仅使用唯一且完整匹配的章节标题，不按数组序号猜测。保留网站自己的章节访问权限处理。移除了合成指针事件和无效的 `progressChapterUid` 地址回退；日志区分「收到真实点击」和「URL 与目标章节标题已确认」。只在顶层页面运行，避免给内嵌问答页面重复注入主题。

安装时在 Tampermonkey 中更新已有脚本为 `dist/weread-feishu-ui.user.js`，保存后刷新阅读页。启动日志应显示 `v0.5.9`。构建会自动同步根目录的同名脚本，不需要手动复制，也不必每次删除重装。

开发验证：`npm run check`；本机安装 Edge 后运行 `npm run test:edge`。后者在独立、未登录的 Edge 中加载真实微信读书页面和完整构建脚本，使用鼠标坐标检查命中节点并验证章节 URL、标题、正文变化、刷新、滚动、缩放及恢复原貌。它不接管日常浏览器的登录会话，也不等于 Tampermonkey 登录态验收。网站重新排版期间应等待原生阅读器就绪再切章。

目前主要包括：

- 飞书云文档风格的首页
- 更简洁的阅读页面
- 文档式正文排版
- 层级目录与章节导航
- 保留微信读书原有的目录、笔记、阅读设置等能力
- 支持在飞书界面与微信读书原界面之间切换

简单来说：**让微信读书网页版看起来更像在飞书里看文档。**
